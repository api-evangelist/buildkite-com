The Elastic CI Stack for AWS now supports Ubuntu 24.04 LTS as an alternative to Amazon Linux 2023 for Linux agents. Ubuntu images are available for both x86-64 and ARM64 instances. Ubuntu can be selected with either supported deployment method: For CloudFormation, set the LinuxDistribution parameter to ubuntu2404 in Elastic CI Stack for AWS v6.70.0 .
