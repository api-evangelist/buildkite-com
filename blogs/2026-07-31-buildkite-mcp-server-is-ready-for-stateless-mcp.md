The Model Context Protocol has gone stateless—and Buildkite is ready. The Buildkite MCP Server is now compliant with the MCP 2026-07-28 specification across both the open-source server and the Remote MCP Server . The headline change transforms MCP from a bidirectional, stateful protocol into a stateless request-response protocol.
