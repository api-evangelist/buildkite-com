Buildkite's GitHub Actions OSS plugin is in public preview. You run your compatible GitHub Actions workflows in Buildkite unchanged, evaluate as you go, and move to a full Buildkite pipeline when you're ready. This release adds reusable workflows, Docker-based actions, and service containers.
