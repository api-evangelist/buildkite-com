Run a pipeline schedule as configured, or customize a one-off build without changing the schedule. Helpful when you need to validate your schedules before turning them on. Two actions on the schedule page make the choice clear: Run now asks for confirmation, then creates a build using the schedule's saved message, commit, branch, and environment variables.
